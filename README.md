# 郊野學園考察團

WebGL 教學遊戲，地圖只覆蓋長洲及附近海域，使用直升機而非無人機。這不是已上線的個人版 `hkrgb/hk-drone-flight`。

試玩：**https://caritasfsc-anthony.github.io/cheung-chau-helicopter/?v=s1-20261127-2036**

本機開發可用：http://127.0.0.1:8771/?v=s1-20261127-2036

手機省資源可加 `&quality=low`。除錯可加 `&debug=1`。

版本：**s1-20261127-2036**。從長洲南面海域海拔 589 米、朝向 340° 起飛；桌上版與手機都顯示左下 WASD、右下 J／Q／R／M 圖示加字母控制鍵；小地圖圖示改按實際畫布邊緣夾位；指南針字母下有半透明圓底。新增輕量按鈕亮光／按下縮放與 480ms 過場（輕微放大、提亮及暖金光暈），支援減少動態效果設定；指南針使用明確尺寸，直升機連同主／尾旋翼等比例放大 2 倍（9 米 → 18 米），追尾鏡頭不變。開場先顯示標題畫面，按 START 後翻頁看考察團故事；第 6 頁「準備出發」之後先進入兩頁遊戲教學，再進入第一個尋人標題（尋找莫博士）。主選單「開始新遊戲」會由開場故事第一頁再播六頁故事，然後進入兩頁教學，再進入第一個尋人標題；「繼續遊戲」與「讀取進度」會跳過故事同教學。「再飛一次」仍直接回到第一個尋人標題。每個任務的尋人標題（包括第 2、3、4、5 章）按 LET'S GO 後，都會先完整播放約 6 秒起飛短片（鋪滿 16:9 舞台、無播放器外框），然後才進入三維畫面；接近結尾時以約 1 秒交叉淡化轉入已在起飛點就緒的三維畫面，同時短片聲音淡出、背景音樂淡入。其後每個角色都是：標題頁 → 起飛短片 → 由同一南面海域起飛點再出發（只重設位置，不重設 10 分鐘共用計時）→ 飛行（提示含方位與地貌）→ 找到後的短動畫（正確 16:9、靜音以免打斷主題曲，鋪滿舞台且不裁切角色或名稱；由 0 播至 2.16 秒後即時回到開頭循環重播；右下有真實繼續按鈕，可於播放期間繼續）→ 關卡之間的故事頁 → 下一節。飛行期間循環播放背景音樂。打開標題畫面就會嘗試播放主題曲（`media/theme.mp3`），唔使等 START；若瀏覽器攔截自動播放，喺頁面上嘅第一次點擊或按鍵就會開始。主題曲喺故事頁、尋人標題同找到目標畫面繼續循環；按 LET'S GO 會把主題曲淡出以免蓋過起飛短片聲音，找到目標時會把飛行背景音樂降低並從頭播放主題曲，再進入下一節飛行時改回背景音樂。飛行畫面同主選單右上有簡潔靜音掣同全屏幕掣；標題／START 封面只顯示右上角全屏幕掣（不顯示靜音掣），方便先開全屏幕。開場故事、教學、尋人標題、找到短片、起飛短片同結局短片會隱藏這兩個掣，以免遮住畫面右上角的標誌。切走分頁會暫停聲音，回來再繼續。救出斑班長後會進入「尋找小螢銀包」關卡（東南洞穴，離地 30 米）；尋回銀包後會直接播放約兩分鐘的結尾短片（不再顯示找到畫面或銀包故事頁），播完或按「跳過」才到結果畫面；結果畫面不顯示飛行時間。約 600 米內提示盒出現加厚 1.1cqh、雙層反向旋轉及柔光幻彩邊，約 300 米才顯示黃圈與距離。飛行畫面置中於 16:9 舞台，多餘空間為黑邊；日間天空以著色器畫出輕柔、緩慢漂移的雲層（無需額外貼圖）。全程最低離地高度 30 米；checkpoint（黃圈中心及距離標記）均按目前載入的地形高程即時計算，以離地高度（AGL）標示，並非固定海拔；海面最低視為海拔 0 米。尋找小螢為當地地面／海面以上 50 米，其餘關卡（包括尋找小螢銀包）為 30 米。黃圈半徑由 52 米縮至 22 米，避免降低後下半圈插入平坦地面／海面。起飛位置、海拔 589 米及 340° 航向不變。標題畫面按 START 會進入主選單（開始新遊戲／讀取進度／儲存進度；進行中可繼續遊戲）。左上「主頁」或結果畫面的「返回標題」回到主選單，並保留當前進度，不會重設關卡。結果畫面「再飛一次」會回到第一個尋人標題，不再重播開場故事或教學。每個篇章要隨機答對三條題目（同一篇章內已出現過的題目在仍有未出過的題時不會重複），失蹤者提示、黃圈同位置才會解鎖。進度可存入三個本機檔案位，並會在答對、解鎖或回主頁時自動儲存。右上指南針為 north-up，指針隨航向轉動。直升機模型於起飛後背景下載，同一局自動顯示。圖磚未到也可先開始並操控；等候時會顯示計數、參考棋盤（並非真實海陸）及重試。

## 操作與任務

- 鍵盤：Q 左轉，R 或 E 右轉，W／A／S／D 平移，J 或空白鍵升高，M、Shift 或 X 下降，C 切換視角
- 桌上版與手機都會顯示畫面左下 WASD、右下 J／Q／R／M 圖示加字母控制鍵；手機請打橫使用，建議先開全屏幕
- 每一節（包括第 2 至第 4 節）都從同一起飛點出發：長洲南面海域（約北緯 22.1892017、東經 114.0360482），朝向 340°、海拔 589 米；離第一站約 2.6 公里，避免一出場或過關後過快到達目標。各節的目的地座標不變
- 四節尋人（飛近後才顯示目標圖形）：莫博士、金剛仔、小螢、斑班長
- 約 600 米內提示盒現幻彩邊，約 300 米顯示黃圈與距離；飛入 70 米範圍即找到該角色，無需返回碼頭或降落
- 標題與故事畫面不提供自由飛行；任務在長洲範圍內進行，沒有中環等出發點
- 第一次進入飛行任務前播放 `media/intro.mp4`；飛行時循環播放 `media/bgm.mp3`。重玩或由標題再出發會再播短片，點一下畫面或按 Esc 可開始淡入遊戲，但畫面上不設略過掣


## 飛行儀表與地理考察加油站

飛行畫面左上儀表只保留海拔、地速、航向；先前擠在航向右邊、標籤被裁走而剩下一個數字的「電量」百分比已移除。能量改為航向與指南針之間的圖形能量條（閃電加約 10 格），對應原本 10 分鐘共用飛行時間，格數隨剩餘時間減少。探索模式顯示滿格。

任務飛行時，天空會出現一個熱氣球（約 160 米高，籃底約海拔 320–400 米，清楚高於島上地形），標誌會轉向鏡頭並輕微起伏。第一次出現會在起飛航向正前方、長洲可玩範圍的北面天空，從預設起飛畫面就能見到；小地圖不標示熱氣球，避免與任務目的地混淆。飛近約 150 米會暫停飛行並打開「地理考察加油站」問答；每次靠近都會先顯示「考考你」介紹頁，再進入該次問題。題目畫面跟 PDF 的排版同字級（大標題、大題幹、較高的粉紅色選項掣），手機橫向都睇得清楚，並且唔顯示主頁／全屏幕等飛行儀表。載入問題、介紹／題目／對錯頁之間，以及答完返回飛行，都會用約 0.3 秒的淡入淡出，避免硬切。現時共四條海岸地貌題，每局每條只用一次，順序隨機。答對會把能量加滿（計時歸零，可飛更久）；答錯不加能量。無論對錯，按下一頁後熱氣球會在距離上次至少約 380 米、仍在長洲上空的新位置再出現；四題都答完後該局不再出現熱氣球。返回主頁或「再飛一次」會重設題庫與熱氣球。此改動不改動四個尋人目的地座標（包括小螢離地 50 米）。第三題其中一個選項依地理名稱寫成「海蝕穴（Sea cave）」，不使用設計稿按鈕上多出來的「與」字。

熱氣球籃子裡有地球角色（從前方接近時面向鏡頭），與氣球標誌同向。執行檔仍為輕量 WebGL1 模型（`balloon-model.js` 與壓縮貼圖，含角色貼圖），不含原始 3D 檔案。

## 限制

沒有立體樓宇；市區是航拍貼在地面高程上。真手機未在此版本驗證。慢網絡仍需等候圖資，不能保證高清即時顯示。地圖被限制在長洲及約 1.5 公里周邊海域。
